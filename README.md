# project
Структура проєкту
Технічне завдання (ТЗ)
Опис мети, вимог та очікуваних результатів.
Формування датасету
Збір, очищення, анотування або вибір готових даних.
Вибір та запуск моделі
Створення, тренування та оптимізація моделі машинного навчання.
Вибір та оцінка метрик
Аналіз якості моделі за допомогою відповідних метрик.
Формування звіту з результатами
Висновки, графіки, отримані результати та аналіз.
Мета проєкту
Розробити та оцінити модель машинного навчання відповідно до поставленого завдання.
